## Project operating manual

**Read [figtro-CLAUDE.md](figtro-CLAUDE.md) fully before doing anything on this project.** It is the authority here and overrides habits or shortcuts. Most importantly: work one section at a time, stop and wait for explicit confirmation after each one, reuse shared components instead of rebuilding them, and pull real values from the Figma MCP rather than guessing.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
